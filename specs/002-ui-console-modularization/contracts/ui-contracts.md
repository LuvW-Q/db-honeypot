# 控制台 UI 契约

**Feature**: `002-ui-console-modularization` | **Date**: 2026-11-25

本文件把 spec 的视觉/交互要求（FR-090–FR-113、附录 B/C）固化为可核对契约：壳层尺寸、
路由元数据、四页区域、组件状态、交互语义、禁用控件、格式化与可访问性规则、离线要求
与视觉判定方法。区域核对表与浏览器检查脚本按本文件执行；实现偏离本文件必须改动
spec 附录 B 或本文件并留下理由。

## 3. 四页区域契约

区域 ID 与 spec 附录 C 一一对应；下列为每个区域的最低内容与核对点。

### 3.1 首页概览 `#/`

| 区域 | 最低内容 | 核对点 |
| --- | --- | --- |
| `OV-HEAD` | h1 + 等宽副标、演示库就绪标记、范围切换（今日 24H / 最近 7 天 / 全部历史） | 范围切换后 KPI 与趋势同步变化；激活态为 `bg-primary-container` |

| `OV-TREND` | 每日趋势面积图：标题与副标、图例（爆破/拖库/踩点扫描）、网格、峰值标注、脚注口径 | 序列颜色 = 意图族色；峰值标注指向实际最大点；空数据不绘制假线 |

## 6. 交互语义

### 6.1 时间范围（概览）

点击 24H/7天/全部 → 更新 hash `?range=` → 重新请求 `/api/overview?range=` 与
`/api/trend` → KPI 与趋势同步更新；请求期间旧数据保留 + 局部 loading；失败显示错误条
与重试按钮。禁止只改按钮样式（附录 B 第 8 条）。

### 6.2 筛选与排序（列表/详情）

- 任一筛选变化 → 重置到第 1 页 → 真实请求；hash 同步，刷新恢复；
- 组合筛选无结果 → `AT-EMPTY`/`AL-EMPTY`；
- 非法 hash（如 `severity=xyz`）→ 回退默认值并在控制台无 error（用 `router.replace` 修正）；
- 排序下拉选项：风险分降序、最近出现降序、首次出现降序、累计会话降序（`total_connections`）。

### 6.3 分页

`page_size` 固定 20（100 上限内）；首/末页按钮禁用；越界页码修正为有效页并提示。

### 6.4 告警已读与批量

- 单条：点击"标记已读" → `PATCH /api/alerts/{id}` → 成功后本地更新 + 重新取统计；
  失败 → Toast 显示 `message`，状态回滚；
- 批量：勾选 ≥1 条 → "批量标记已读" → 逐条 PATCH（并发 2）→ 全部成功 Toast
  "已标记 N 条为已读"；部分失败 Toast 列出失败条数与原因，失败项保持未读并高亮；
  请求期间按钮禁用 + 进度文本；已读项自动从"未读"页签移除。

### 6.5 刷新

页头"现场刷新数据"重新请求当前页全部接口；页脚/页头显示最近成功更新时间；
失败时保留旧数据并显示错误条；禁止假 loading 动画或假时间戳（附录 B 第 9 条）。

### 6.6 会话证据跳转

告警卡"查看会话证据" → `#/attackers/{source_ip}?session={session_id}`；
详情页加载后高亮该会话行并滚动到时间线，时间线事件按该会话过滤。

### 6.7 降级

`/api/health` 返回 `degraded`/503 或请求失败 → 全宽 `StateBanner`（error）+
"数据库不可用，以下为最近一次成功数据"（若有）+ 重试按钮；页面不得白屏、不得显示
0 值冒充真实数据（SC / FR-113）。

### 6.8 空态

每页空态提供可执行动作：概览 → "刷新数据"；列表 → "清除筛选条件"；告警 → "重置所有
筛选器"；详情 → "返回攻击者列表"。禁止引用不存在元素的空态开关（附录 B 第 10 条）。

## 7. 格式化规则

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 时间 | 统一 UTC+8，`YYYY-MM-DD HH:mm:ss`；相对时间仅用于"最近"列（<1 分钟→"刚刚"，<60 分钟→"N 分钟前"，<24 小时→"N 小时前"） | `2026-11-24 18:42:07` |
| 时钟 | 页头 `LIVE UTC+8` 每秒刷新真实时间 | `LIVE UTC+8 · 18:42:07` |
| 大数 | 千分位；≥10000 不缩写（保持与数据库一致，便于核对） | `18,920` |
| 百分比 | 1 位小数；分母 0 → `—` | `94.2%` |
| 风险分 | 整数 0–100；条宽 = 分数% | `78` |
| 时长 | `<60s` → `N 秒`；否则 `M 分 S 秒`；无数据 → `—` | `6 分 12 秒` |
| IP | 等宽字体；网络归属为徽标 | `192.168.10.84` |
| SQL | 等宽、单行截断 120 字符、悬浮显示完整（已脱敏）；禁止尖括号转义错误 | `SELECT * FROM fake_users …` |
| 编号 | 会话 `sess_…`、告警 `#12`、事件 `#345` 等宽 | `sess_20261124_01` |

数值必须与接口/SQL 一致（SC-020）；禁止前端四舍五入导致与数据库不符（百分比除外）。

## 8. 可访问性与语义

- 每页唯一 `<h1>`；标题层级 `h1 → h2 → h3` 不跳级；
- 导航当前项 `aria-current="page"`；图标按钮必须有 `aria-label`；装饰图标
  `aria-hidden="true"`；
- 颜色不是唯一信息载体：等级同时有文字/点形；风险条同时有数值；
- 正文对比度 ≥ WCAG AA（4.5:1），大字号/关键数字 ≥ 3:1；深色背景上 `on-surface-variant`
  仅用于次要文字且 ≥4.5:1；
- 焦点可见（`focus-visible` 描边使用 `primary`）；键盘可达所有交互控件；
- 尊重 `prefers-reduced-motion`：状态点脉冲动画在该偏好下关闭（不使用装饰性长动画）。

---

## 9. 离线与资源

- 字体、图标、Logo、favicon、图片全部本地构建产物（R-03）；构建后 `index.html` 与
  CSS 中不得含 `http(s)://` 外链（字体/图标/脚本）；
- 断网时四页正常渲染（字体已缓存于产物），外网请求数 0（SC-026）；
- `<link rel="icon">` 随路由切换（4 个本地 SVG）；`<title>` 随路由切换（§2）；
- 不加载任何分析/统计第三方脚本。

## 10. 视觉验收判定

| 判定 | 定义 |
| --- | --- |
| 一致 | 区域的内容结构、层级、令牌取值、组件形态、交互与原型一致（数据差异除外） |
| 差异（已登记） | 因真实数据口径/禁用策略/原型缺陷裁定导致的不同，已在附录 B（含补充 21–28）登记理由 |
| 不接受（待修） | 结构缺失、令牌错用、颜色/字号/间距错误、交互失效、溢出/重叠 |

- 每页 20 处视觉取值抽样：记录"元素、CSS 属性、期望令牌/取值、实际计算值"，
  命中率必须 100%（SC-018 的令牌部分）；
- 区域一致率 = 一致区域数 / 区域总数；四页合计 ≥95%；

## 12. 主题（浅色/深色，FR-133、FR-134）

- **模式**：`system`（默认，跟随系统）、`light`、`dark`。持久化键 `localStorage["dbh-theme"]`，
  取值仅 `system|light|dark`；无存储或不可读时按 `system` 处理。
- **切换入口**：页头（SHELL-HEADER）"现场刷新数据"左侧的圆角矩形按钮（`rounded` = 4px，
  `data-theme-toggle`），点击循环 `system → light → dark → system`；按钮文案与图标分别为
  `跟随系统/brightness_auto`、`浅色/light_mode`、`深色/dark_mode`，`aria-label` 形如
  `主题：跟随系统（深色）`，`title` 追加下一步提示。
- **实时跟随**：`system` 模式下监听 `matchMedia('(prefers-color-scheme: dark)')` 的 `change`，
  系统外观变化立即切换 `html.light`/`html.dark`，不刷新、不重取数；手动覆盖后不再跟随，
  直到切回 `system`。
- **无闪烁**：`index.html` 内联引导脚本在 CSS/JS 之前按"存储覆盖 > 系统偏好"设置
  `html` class 与 `color-scheme`；`src/main.ts` 挂载前调用 `initTheme()` 接管监听。
- **令牌**：`src/assets/main.css` 中 `:root`（深色）与 `html.light`（浅色）各定义同一组
  `--c-*`（RGB 三元组）与 `--chart-*`/`--shadow-panel`；`tailwind.config.js` 的颜色一律为
  `rgb(var(--c-*) / <alpha-value>)`。浅色取值参照 light 原型：画布 `#f8fafc`、卡片 `#ffffff`、
  文字 `#0f172a`/`#64748b`、描边 `#e2e8f0`、主色 `#0284c7`、强调 `#0f766e`，严重度在浅色下
  加深一档以保证对比度。
- **图表与内联样式**：`TrendChart`、`IntentDonut`、图例、Logo 的系列色/网格/轨道/提示框
  必须引用 `var(--chart-*)` 等变量；禁止在 `.vue`/`.css` 中出现裸色值。
- **验收**：`verify/token-audit.mjs` 校验深浅两套令牌齐全且无裸色值；`verify/run-check.mjs`
  校验系统外观实时跟随、三态循环、`localStorage` 持久化、刷新后保持，并对四页做浅色渲染
  检查（区域/标题/溢出/资源错误）与截图；浅色基线截图存入 `evidence/visual/baseline-light/`。
